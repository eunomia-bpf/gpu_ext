# MoE-Infinity experiment instructions

- Never generate, refresh, compare, or record file/content hashes, checksums,
  or digests for this workload, and never use them as experiment gates or
  evidence.
- Use normal Git commits, upstream source revisions, explicit file inventories
  and sizes, patch-application checks, build inspection, tests, and real
  correctness/engagement runs instead.
- Git commit IDs are ordinary commit/push bookkeeping and are not prohibited.
