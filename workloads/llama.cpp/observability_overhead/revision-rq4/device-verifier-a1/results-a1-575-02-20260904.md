# Device-verifier A1 on RTX 5090

The A1 campaign completed on driver 575.57.08 with the verifier-enabled
CUDA/LLVM runtime at bpftime commit `8eb27cf`. It used the real Table 1
`kernelretsnoop` and `threadhist` objects. The baseline, both A0 cells, and all
40 randomized A1 cells passed without retry. The independent analyzer reports
`complete: true`, `run_status: valid`, and no errors.

| device object | STRICT samples | median | mean | range | 95% bootstrap CI of mean |
|---|---:|---:|---:|---:|---:|
| `kernelretsnoop` (60 instructions) | 10 | 141.191 ms | 141.266 ms | 140.960--141.633 ms | 141.147--141.398 ms |
| `threadhist` (13 instructions) | 10 | 11.762 ms | 11.767 ms | 11.740--11.832 ms | 11.753--11.785 ms |

Each tool has ten fresh STRICT/NO_VERIFY process pairs, with STRICT first in
five pairs and NO_VERIFY first in five. Every STRICT target PID has exactly one
runtime timing record, one acceptance for the exact program and attachment,
and one exact map descriptor. Every NO_VERIFY target PID has exactly one skip
record and zero timing, acceptance, map, rejection, unavailable, foreign-PID,
or malformed records.

All 42 instrumented A0/A1 cells reproduce the exact 47-byte baseline output.
For `kernelretsnoop`, every cell records all 720,896 expected callbacks with the
complete launch/coordinate/multiplicity oracle and zero drops. For `threadhist`,
every cell records 720,896 samples and a complete 1,048,576-entry (8 MiB)
readback. Per-cell process cleanup, private shared-memory removal, GPU safety,
and runtime/object gates all pass.

The measured quantity is only the `steady_clock` interval around one call to
`verify_gpu_program`. It is a one-time admission cost per fresh object/process,
not per callback, application latency, JIT/attach/bootstrap time, or steady-state
throughput overhead. NO_VERIFY is an explicit matched path control and is not
reported as a fabricated zero-latency measurement. S0 separately measures the
steady-state STRICT-versus-NO_VERIFY effect.

The earlier `a1-575-01` attempt remains retained as a failed build-freshness
check; it contributes no sample here.
